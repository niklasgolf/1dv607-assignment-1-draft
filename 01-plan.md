# Task 1 - Plan

1. Read the complete problem description and all the use cases once to get an understanding of how the laundry room booking system works.

2. Read the text again and write down nouns that describe people, places, physical things, events, transactions, rules and information that may need to be stored. At this stage it is better to include too many nouns than too few.

3. Make a first list of candidate conceptual classes from the nouns that seem important to the domain.

4. Write a short explanation for each candidate about why I think it could be a conceptual class.

5. Look through the candidates and find duplicates or different words that seem to describe the same concept.

6. Remove things that belong to the software rather than the real-world problem domain, for example database, login screen or buttons.

7. Check if some candidates are actually attributes that belong to another conceptual class instead of being classes themselves.

8. Check people, places, physical objects and historical information again to see if something important has been missed.

9. Create two lists: Accepted Candidate Conceptual Classes and Discarded Candidates. For discarded candidates, write a short explanation of why they were removed.

10. Stop here before creating the domain model. The domain model, associations and multiplicities will be handled in Task 2.
